# Poker Telegram Mini-App 🃏

Проект представляет собой **Telegram Mini-App** для игры в покер с друзьями. Приложение позволяет создавать игровые комнаты, объединяться в них по коду и играть в реальном времени.

**Рабочая версия (деплой):** Запускается через Telegram-бота [@poker043kbot1k_bot](https://t.me/poker043kbot1k_bot) в режиме Mini-App. *(Прямая ссылка на сайт корректно работать не будет, так как приложение завязано на окружение Telegram).*

## Ключевые возможности

*   **Мультиплеер в реальном времени**: Обмен данными и синхронизация состояния игры происходят мгновенно благодаря WebSockets (`Socket.IO`).
*   **Интеграция со сторонним API (Баллы)**: Игровые балансы и поинты подтягиваются из внешнего сервиса по API с защищённой HMAC-подписью.
*   **Игровые комнаты**: Возможность создавать приватные комнаты и приглашать друзей.
*   **Локальная база данных**: Сохранение статистики игроков (сыгранные игры, победы, оборот средств, лучшая рука) с использованием Prisma ORM и SQLite.
*   **Оценка комбинаций**: Выявление выигрышных покерных рук с помощью библиотеки `pokersolver`.
*   **Современный стек и архитектура**: Фронтенд построен на React с использованием архитектурной методологии FSD (Feature-Sliced Design) для хорошей масштабируемости.

## Технологический стек

### Frontend (`/front`)
*   **Фреймворк**: React 19 + TypeScript
*   **Сборщик**: Vite
*   **Стейт-менеджер**: Zustand
*   **Связь с сервером**: `socket.io-client`
*   **UI/Иконки**: `lucide-react`
*   **Архитектура**: Feature-Sliced Design (FSD)

### Backend (`/back`)
*   **Окружение**: Node.js + Express
*   **База данных и ORM**: SQLite + Prisma (`@prisma/client`)
*   **WebSockets**: Socket.IO
*   **Логика покера**: `pokersolver` (для вычисления сильнейших комбинаций рук)
*   **Язык**: TypeScript

## Как запустить проект локально

Проект состоит из двух частей: Backend и Frontend. Обе части необходимо запускать одновременно (в разных терминалах).

### 1. Подготовка и запуск Backend (Серверная часть)

1. Перейдите в папку бекенда:
   ```bash
   cd back
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Создайте файл `.env` (если его нет) в папке `back` и укажите необходимые переменные окружения:
   ```env
   DATABASE_URL="file:./dev.db"
   PORT=3000
   
   # Данные для интеграции со сторонним сервисом балансов
   DB_API_URL="https://tapapi.14th.ru"
   POKER_SECRET_KEY="свой ключ"
   CLIENT_ID="свой client_id"
   ```
4. Примените миграции Prisma для создания таблиц базы данных:
   ```bash
   npx prisma db push
   # или npx prisma migrate dev (если вы используете систему миграций)
   ```
5. Запустите сервер для разработки (используется `nodemon`):
   ```bash
   npm run dev
   ```
   *Сервер запустится и будет готов к приёму WebSocket подключений.*

### 2. Подготовка и запуск Frontend (Клиентская часть)

1. Откройте **новый терминал** и перейдите в папку фронтенда:
   ```bash
   cd front
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Проверьте конфигурацию клиента. Убедитесь, что сокеты подключаются к правильному адресу бекенда (например, `http://localhost:3000`).
4. Запустите клиентское приложение:
   ```bash
   npm run dev
   ```
5. Перейдите по ссылке, которую выдаст Vite (обычно это `http://localhost:5173`), чтобы открыть приложение.

## Структура проекта

### `back/` (Backend)
*   `prisma/` — схемы базы данных Prisma.
*   `src/`
    *   `db.ts` — инициализация Prisma-клиента.
    *   `deck.ts` — логика колоды карт (генерация, тасование).
    *   `gameLogic.ts` — правила покера и управление стадиями игры.
    *   `index.ts` — точка входа сервера, настройка Express и Socket.IO событий.
    *   `services/` — сервисы для работы со статистикой и API.

### `front/` (Frontend - FSD)
*   `app/` — глобальная конфигурация (стили, инициализация).
*   `pages/` — страницы приложения (Home, Lobby, Game, Stats).
*   `widgets/` — самостоятельные блоки UI (Game Controls, Poker Table, Sidebar).
*   `features/` — бизнес-логика пользователя (создание комнаты, выход).
*   `entities/` — бизнес-сущности (Card, Player, Board, Room).
*   `shared/` — переиспользуемый код (API, UI компоненты, хуки, утилиты).
